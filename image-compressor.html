How to compress an image

  1. Select a JPG, PNG or WebP image.
  2. Choose WebP or JPG as the output format.
  3. Adjust the image quality slider.
  4. Click Compress Image.
  5. Compare file sizes and download the result.

What format should I choose?

WebP: Often provides efficient compression and supports transparency.

JPG: Widely compatible and suitable for photographs, but does not support transparency.

PNG input: You can reduce its size by converting it to WebP or JPG. This changes the image format.

Private processing

Your image is processed inside your browser with the Canvas API. Image contents are not uploaded to FreeAITools servers.

Compression does not guarantee a smaller result. Some image metadata may be removed. Animated images are not supported.
