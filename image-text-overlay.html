How to add text to an image

  1. Select a JPG, PNG or WebP image.
  2. Write a headline, caption or multiple lines.
  3. Choose the font, text size and color.
  4. Select text alignment and one of nine positions.
  5. Customize the background box if needed.
  6. Preview the result and download your image.

Make headlines and social media graphics

Use an image text overlay to create announcements, social media graphics, blog illustrations and simple promotional posts. Add a readable background box over busy photos.

Private image editing

This tool uses the browser Canvas API. No external image-processing library, paid API or user account is required.

Important limitations

This tool supports static images only. Font availability depends on your device. Very long text is reduced in size to fit, but may become difficult to read.

PNG and supported WebP outputs can retain transparency. JPG uses a white background. EXIF, GPS and other metadata may be lost.

Frequently Asked Questions

Is Image Text Overlay free?

Yes. No payment or account is required.

Can I add multiple lines?

Yes. Press Enter in the text editor. Long lines wrap automatically.

Can I use Thai text?

Yes, if the browser has a font supporting Thai characters.

Can I add a background behind text?

Yes. Choose the background color and opacity or turn the box off.

Can I adjust text position?

Yes. Choose from nine positions on the image.

Will image dimensions change?

No. Output dimensions match the decoded original image.

Can I download JPG and WebP?

Yes, if your browser supports the selected format.

Are my images uploaded?

No. Image processing happens locally in your browser.
